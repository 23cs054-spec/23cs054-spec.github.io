SkyCast Weather

A high-performance weather application delivering real-time forecasts and 5-day projections using the OpenWeatherMap API.

Author / Role
Hareram Kushwaha (Creator)
Tech Stack
JavaScript (ES6), HTML5, CSS3, REST API
Category
Frontend API Integration
Repository
GitHub Repo

The Problem

Mainstream weather portals are often cluttered with invasive video ads, heavy tracking scripts, and slow initial rendering times that frustrate users who simply want to check today's temperature and upcoming weekend forecasts.

SkyCast was built to provide a clean, uncluttered interface that fetches and renders meteorological observations in milliseconds, using an atmospheric glassmorphism aesthetic that shifts dynamically to reflect conditions.

My Role & Technical Stack

I engineered the application using native web standards:

  • JavaScript: Vanilla ES6+ modules utilizing async/await and the Fetch API to parse JSON responses from OpenWeatherMap.
  • CSS Styling: Modern CSS with backdrop-filter glassmorphism cards, responsive flex layouts, and condition-based background styling.
  • API Integration: OpenWeatherMap current weather and 5-day forecast endpoints with input normalization and error handling.

Key Features

Real-Time Conditions

Live temperature readings, feels-like metrics, humidity percentages, wind speed, and atmospheric pressure.

5-Day Forecast Projection

Aggregates timestamped forecast readings into daily high/low summaries with corresponding meteorological icons.

City Search & Validation

Search cities globally with defensive error handling alerting the user to invalid or unfound city queries.

Technical Decisions

Zero Framework Dependencies

By utilizing native DOM manipulation and the native Fetch API without React or Vue, the entire application bundle is tiny, ensuring instant load times and negligible memory consumption on low-end devices.

Graceful Error Boundary Handling

Network failures or invalid city inputs are trapped within try/catch blocks that update UI status indicators without triggering uncaught browser console exceptions.

What I'd Improve Next

  • Client-Side Cache with TTL: Cache successful city lookups in localStorage with a 15-minute time-to-live to prevent duplicate API requests.
  • Browser Geolocation: Add an automatic "Use My Current Location" button using the HTML5 Geolocation API.
  • Air Quality Index (AQI): Integrate the OpenWeatherMap Air Pollution API to display particulate matter (PM2.5 / PM10) readings.
