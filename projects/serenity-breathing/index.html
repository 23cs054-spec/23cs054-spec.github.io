Serenity Breathing

A digital mindfulness and wellness web application designed to support breathwork exercises, BMI tracking, and personal mood insights.

Author / Role
Hareram Kushwaha (Creator)
Tech Stack
React, TypeScript, PWA, Firebase
Category
Frontend / PWA
Repository
GitHub Repo

The Problem

Many wellness and breathing exercise tools are either locked behind native mobile app store walls or overloaded with intrusive subscriptions and distracting advertisements. Users seeking a quick, calming breathing routine on desktop or mobile need an immediate, lightweight application that loads quickly and works offline.

The goal of Serenity Breathing was to create a focused, accessible, and privacy-conscious web app that guides users through scientific breathing techniques (such as box breathing and 4-7-8 cycles) without friction, complete with helpful wellness utilities like BMI estimation and mood logging.

My Role & Technical Stack

I designed and built the application independently from scratch:

  • Frontend: React with TypeScript for type-safe component state management and clean interface modularity.
  • PWA Integration: Web app manifest and service worker configuration allowing the app to be installed directly to home screens and accessed without a network connection.
  • Backend Services: Firebase for authentication and persistent cloud storage of user preferences and session history.
  • Styling: Responsive CSS with smooth timing functions for the breathing animation loop.

Key Features

Guided Breathing Cycles

Visual and timed prompts guiding inhalation, holding, and exhalation intervals with customizable pacing.

Health BMI Tracker

Interactive calculator computing Body Mass Index with immediate category breakdowns and recommendations.

Mood Insights

A simple reflection log allowing users to note their mental state before and after completing breathwork sessions.

Technical Decisions

TypeScript for Timing State Safety

Breathing cycles rely on strict state transitions (INHALE → HOLD → EXHALE → REST). Defining union types and strict interfaces prevented state race conditions during timer intervals.

PWA Architecture for Zero-Friction Access

By packaging the application as a Progressive Web App, users avoid having to download a large mobile app store bundle while still benefiting from standalone display mode and offline capability.

What I'd Improve Next

  • Audio Haptics & Chimes: Add optional subtle ambient sound frequencies and Web Vibration API haptic pulses for eyes-closed meditation sessions.
  • Local-First IndexedDB Sync: Allow full offline data logging with automatic conflict-free synchronization to Firebase when connectivity resumes.
  • Exportable Summaries: Enable users to export their weekly mindfulness minutes and mood progress as clean markdown or PDF summaries.
