About Me

Background & Engineering Focus

Final-year Computer Science Engineering student at KPRIET, Coimbatore, driven by scalable backend architecture and practical software systems.

“I build systems that don't just work, but scale and endure.”

What I Build

I architect web applications, scalable backend services, and educational systems tools. My technical repertoire spans responsive React and TypeScript frontends (such as Serenity Breathing), multi-tenant server-rendered platforms with PHP and MySQL (such as NexisERP), and secure API backends using Node.js, Express, and SQLite with token authentication (such as the Online Voting System). Beyond web stacks, I simulate operating system mechanics in Python, including virtual memory page replacement and block-based file systems.

How I Work

My engineering philosophy is rooted in clean, self-documenting code, structured commit histories, and rigorous problem solving. Rather than relying on copy-paste workarounds, I study official technical specifications, isolate edge cases, and test components thoroughly. Having solved over 250 algorithmic problems on LeetCode and built 40+ repositories on GitHub, I have learned how every layer of the system communicates — from HTTP request headers to database indexing strategies.

Background & Global Outlook

Originally from Nepal, I moved to Coimbatore, Tamil Nadu, to pursue my Bachelor of Engineering in Computer Science and Engineering at KPRIET (started September 2023, expected graduation around August–September 2027, current CGPA 7.9). Living and studying across borders has fostered a high degree of cultural adaptability, collaborative communication, and grit. I am actively preparing for software engineering internships and junior engineering roles across global teams.
