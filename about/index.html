About Me

Background & Engineering Focus

Computer Science Engineering student at KPRIET, Coimbatore, driven by practical software development and systems fundamentals.

What I Build

I build web applications, backend services, and educational systems tools. My project work spans responsive React and TypeScript frontends (such as Serenity Breathing), multi-tenant server-rendered platforms with PHP and MySQL (such as NexisERP), and secure API backends using Node.js, Express, and SQLite with token authentication (such as the Online Voting System). Beyond web layers, I develop practical desktop simulations in Python, including the OS-Project suite that visualizes virtual memory page replacement and block-based file systems.

How I Work

I prioritize clean code, meaningful commit messages, and thorough documentation. Instead of relying on copy-paste code, I read official documentation, break problems down into testable components, and track my progress through structured GitHub repositories. When building applications, I focus on predictable state flow, semantic HTML, and intuitive user experiences. Learning by building complete projects has taught me how different layers of the software stack communicate — from HTTP request headers to relational database schemas.

Background & What I'm Learning Next

Originally from Nepal, I moved to Coimbatore, Tamil Nadu, to pursue my Bachelor of Technology in Computer Science and Engineering at KPRIET (started September 2023, expected graduation around August–September 2027, current CGPA 7.9). Living and studying in a different culture has strengthened my adaptability and teamwork skills. I am currently deepening my understanding of operating system internals, database indexing strategies, and modern TypeScript architecture while seeking software engineering internships and junior developer opportunities.
